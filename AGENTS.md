# Development workflow

Make all application code changes through GitHub. Lovable is used only for hosting and publication. Do not use Lovable chat to write or modify code.

Do not rewrite published history. The Lovable hosting sync must be connected in project settings; this snapshot alone does not establish sync.

## Application rules
- Keep the five demo routes powered by the existing local demo store; visual redesigns must not add backend dependencies or alter inquiry transitions.
- Define visual colors, editorial framing, and typography in src/styles.css and use shared branding and Button controls so every demo route retains a coherent identity.
- Store downloaded media as asset pointers and use live demo store values for homepage software previews so they reflect the working experience.
